## 0. 企劃定位（不變）

這不只是一個 meme 小遊戲。對象是一位**已永久畢業、再也見不到的 VTuber**，
所以這個遊戲真正的產品是：**「一個隨時可以回去的地方」**。

打肉、60KG 握力器、ガッキー——這些梗是粉絲共同記憶的鑰匙。

**v2 補充的設計濾鏡**（實作過程中確立）：任何新功能先過兩關——
1. **會不會擋到結算截圖／分享？**（分享性 > 儀式感）
2. **會不會拖慢一局的節奏？**（一局幾十秒的輕快感是本體）

## 4. 效能

現況體檢：單檔 60KB JS、無依賴、rAF 主迴圈、HiDPI 上限 2x——桌機無壓力，優化重點在**手機發熱／低階機**與**載入**。

| # | 優先 | 項目 | 說明 |
|---|------|------|------|
| P1 | P0 | **立繪 PNG 壓縮** | win 1.2MB＋lose 864KB 是目前載入的大頭。pngquant 有損壓縮可到 ~25%（畫質無感），或轉 WebP 再省一半。兩張圖從 2MB → 500KB 內 |
| P2 | P1 | **背景離屏快取** | `drawBackground` 每幀重建漸層＋重畫雲海地面；星空 70 顆星每幀 70 次 arc。天空＋地面靜態部分按主題快取到 offscreen canvas，每幀只 drawImage＋動態雲星。手機幀率／發熱直接受益 |
| P3 | P1 | **PWA 離線**（原 4.2「可去之處」） | manifest＋service worker：可安裝到桌面、斷網可玩、二訪秒開。對「永續的小天地」的定位這不只是效能項，是產品項 |
| P4 | P2 | **拳套漸層快取** | `drawFist` 每幀×兩手 createRadialGradient；模組層建一次重用 |
| P5 | P2 | **失焦停渲染** | 目前 paused 只停更新、rAF 照跑照畫。hidden 時直接不排 rAF，回前景再啟動，省電 |

## 5. 可玩性

| # | 優先 | 項目 | 說明 |
|---|------|------|------|
| G1 | P0 | **合成節拍聲／輕 BGM** | S2 連擊、S3 節奏是「節奏遊戲卻沒有節奏聲」——目前只能用眼睛抓拍。WebAudio 合成節拍器（S2 隨 period 加速、S3 對齊譜面），成本低、手感提升是質變。維持零音檔＝零版權風險 |
| G2 | P1 | **無盡連打模式**（F6 殘項） | 通關解鎖：純爽打拚分，肉血量遞增、時間遞減的波次制。「隨時回來打一場」的最短路徑 |
| G3 | P1 | **全 PERFECT 挑戰** | S3 專屬：一個 MISS 即結束。給高手的重玩鉤子，配 C5 圖鑑解鎖卡 |
| G4 | P2 | **S3 第二譜面（高速）** | 固定譜面可背之後，老玩家兩週就膩。加「高速譜」：同譜面 fallTime 縮短＋間隔 0.8x，單關模式選譜 |
| G5 | P2 | **連擊視覺獎勵** | Combo 10/20/30 時大字動畫＋音階上行，強化「不斷連」的動機（分數已有 maxCombo×20，缺的是即時爽感） |
| G6 | P2 | **輕量排行榜（再評估）** | 需後端，先不做。替代方案：分享圖本身就是排行榜——考慮在紀念卡上加「歷史最佳」欄讓比較自然發生 |

## 6. 建議執行順序

| 階段 | 內容 | 理由 |
|------|------|------|
| 下一波 | U1 部署＋OG 卡、P1 圖片壓縮、G1 節拍聲 | 部署讓分享閉環真正成立；壓縮配合部署；節拍聲是手感質變 |
| 第二波 | C1 QTE 擴充、C3 肉演出、U4 HUD、G2 無盡模式 | 內容厚度＋重玩動機 |
| 第三波 | C5 回憶圖鑑、C4 成績單、U2 日文化、P3 PWA | 紀念性＋社群擴散＋永續 |
| 長期分散 | U3 字體、U6/U7 無障礙、P2/P4/P5 效能、G4/G5 | 小步快跑 |
